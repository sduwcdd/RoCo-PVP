## 大世界与管理员授权

大世界未满60级按0星估计；己方60级精灵名称旁可选择0–10星或未指定，不影响PVP固定60级五星。未知星级及缺少成长/资质依据时保留未知，不以PVP补值。

抓包在线时APP直接复用并显示“已复用现有抓包”，不会再弹UAC，也不会停止外部采集进程。中继未运行且当前APP非管理员时，开始抓包才调用Windows管理员授权；取消或启动失败会显示具体原因。首次真实UAC/干净机采集仍待实测。

## 分享版与开发版

分享时只使用dist生成的保护版候选ZIP，不发送项目根目录或单独的开发版EXE。分享版自带Electron与原生后端；个人状态写入本机LocalAppData。当前未签名，第三方许可和干净机/UAC验证仍待完成，详细边界见[发布与保护说明](RELEASE_SECURITY.md)。

点右上角×收起到迪莫托盘；双击托盘恢复，右键“退出”关闭APP自己启动的工作台和HUD。采集进程独立保留，下次打开仍可停止。开发版源码修改后需完整退出再重开，分享版更换完整发布包。

## 使用

1. 双击洛克PVP.exe，控制台自动启动或连接当前版本的工作台。
2. 点击“进入对战工作台”使用APP内窗口；原浏览器存档可通过“打开原浏览器工作台”查看，跨浏览器数据用JSON导入导出。
3. 点击“启动抓包”，在Windows UAC窗口允许管理员权限。网卡默认WLAN，有线连接可修改网卡名称。中继状态、会话密钥、网络包/业务记录和错误显示在同一窗口。
4. 密钥未命中时，先开启抓包，再重新建立游戏连接。
5. 点击“显示HUD”打开左右面板及顶部回合记录；“关闭HUD”可关闭由本APP启动的全部HUD窗口。启动成功需要三块面板均完成加载。

停止服务仅结束本APP的子进程；已有其他服务不被强行关闭。服务版本按lab源码指纹检查，自有后台源码过期时自动重启并验证新版，不再要求手动停止再连接；旧端口被其他服务占用时使用下一可用端口，控制台显示实际端口。数据按端口分开保存，原网页记录仍在原浏览器原地址，切换地址前可导出备份。

抓包启动/停止通过受限PowerShell助手请求管理员权限。停止时核对记录的PID、创建时间和脚本路径，不按进程名批量结束。退出APP会关闭自己启动的工作台及HUD；抓包进程独立保留，下次打开仍可停止。没有绕过UAC。

## 文件与依赖

- 洛克PVP.exe：带迪莫图标的Windows图形入口。
- overlay/desktop.js、desktop_services.js：控制台与进程管理；desktop_preload.js仅暴露固定操作。
- overlay/desktop.html、desktop.css、desktop_renderer.js：连接状态与诊断界面。
- scripts/desktop_capture.ps1：管理员采集助手。
- scripts/build_desktop.py、overlay/Launcher.cs、overlay/dimo.ico：可复现构建。
- artifacts/app/：诊断日志、抓包进程归属与启动结果。

这是本机项目的桌面APP入口，复用已有Electron、.venv-rkpp、vendor及数据目录。请将EXE保留在项目根目录；单独拷贝EXE到别的电脑不构成完整安装包。重建命令：python scripts/build_desktop.py。
