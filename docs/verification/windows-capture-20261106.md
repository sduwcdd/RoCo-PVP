# Windows 采集恢复与取消保护构建

## 已确认原因

用户截图的 WinError 31 来自读取已退出采集进程的映像路径。旧归属记录指向 PID 16576，创建时间匹配，Windows 进程对象已终止，退出码为 0xC0000005；Npcap 服务与 WLAN 当时正常。修复使用带 SYNCHRONIZE 权限的进程句柄先检查退出状态，并处理检查期间退出的竞态。仍在运行的进程查询失败继续报错，停止进程的身份核对及失败保留归属记录规则不变。

原崩溃转储位于用户 CrashDumps 中。最小合成输入 `read_varint(b'\x08', 0)` 能使旧安装版 PYD 发生同样的访问冲突。Cython 3.3.0 及本项目原编译参数将链式初始化 `value = shift = 0` 中的 shift 生成为 NULL，继而传入 PyNumber_Lshift。两个解析器均发现同型结果。拆开初始化后，临时原生模块对 8、300、2^64−1 的解析全部通过；临时源码、编译物与回放产物已删除。另补齐 RkppAnalyzer 初始错误计数，避免未经历密钥失效时访问未初始化属性。
