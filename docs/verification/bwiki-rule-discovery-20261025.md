## 可直接形成版本化条件的文字

依据为 [Terms 修订 7078](https://wiki.biligame.com/nrc/index.php?title=Module:Pets/data/Terms&oldid=7078)，应保留每项条目 ID：

- 1003、1024、1026：本回合刚入场者免疫脱离、返场和紧急脱离。普通脱离选择其他精灵，紧急脱离随机选择。尚不能据此确认随机候选集或多个强制换人同时触发的顺序。
- 1007：蓄力需要 1 回合，下回合释放；蓄力期间免疫所有离场效果。退出免疫能写为条件，主动换人能否取消蓄力等界面行为需单独证据。
- 3009：普通离场包括主动换人或脱离，不包括力竭下场；两类事件不能共用所有触发器。
- 3010：印记跨下场继承，最多同时有 1 种正面和 1 种负面印记。它没有说明同类不同印记如何覆盖、逐个技能的正负分类或层数上限。
- 1005：主动换人入场后，使用技能槽顺序中第一个同时满足能量与迅捷条件的技能；不能排序配招。
- 1010：迸发对应入场后的首次行动。1007 的蓄力步骤是否消耗此机会，仍需核验。
- 1015～1017、1020：应对成功要求敌方对应技能类别，并先手；先手度可以叠加。应对同时成功、换人对技能与同速的统一排序未给出。
- 1033：传动在回合开始向下移动技能，传动值可叠加；越界循环规则和多个传动技能冲突顺序没有直接说明。
- 3005：连击数变更只对已有连击的技能生效；不能把任意普通技能变成多段。
- 3006～3008、3021：沙暴减半地系能耗，暴风雪回合末增加冻结，雨天提升水系威力，雷鸣回合末增加引电。3006 的奇数能耗取整等仍未提供。

这些是资料可支持的条件或系数，不证明完整真实游戏状态转移。

## 能量、魔力与复活仍不足以设默认值

核对了全部 579 技能和 246 特性的 `desc`、`effect_details`、`desc_notes`，及 Config 的全部顶级区域。Config 仅含 `build_form/current_version/features/pet_count/talent_pools`，未提供战斗初始常量。

[Skills 修订 18764](https://wiki.biligame.com/nrc/index.php?title=Module:Pets/data/Skills&oldid=18764) 中：

- `200102/200118/200147/200177/200322` 的特殊特性会以 0 能量起始，不能用作一般初始能量。
- `200215` 多人宿舍允许超出能量上限，但描述没有给出普通上限。
- `200081` 诈死减少魔力损失，`200141` 赎价增加魔力损失，`280019` 御驾亲征指定扣 4 魔力；不能推导普通力竭扣除量或双败顺序。
- `200230` 不朽指定力竭 4 回合后复活，仅支持该特性的文本时长；不能推导一般复活规则、计数边界或完整回归生命/能量。

因此普通初始/上限/每回合能量、一般复活和完整胜负判据仍不能凭此设为默认真值。
