# 通用机制接入与验证

本轮在现有工程渐进接入，不改变原 BWIKI 快照、发布的规则配置、真实对战记录和固定阵容。安装包只读。以下是构造回合与软件测试结果，不是游戏实战校准。

## 已接入实际试战

| 机制 | 实现与边界 |
|---|---|
| 训练师魔力 | 双方各六只时启用 PVP5001→BATTLE340005：4点魔力，精灵力竭扣1、对方制胜点加1。第四次力竭即终结，不必打倒六只。每个成员活→倒下边沿记账，重复收尾不重复扣除；复活再倒下可重新记账。小阵容明确保留独立机制试验模式。 |
| 防御与应对 | 11个来源绑定防御配置，按对方行动类别判应对，减伤在剩余HP裁剪前执行，附带属性/能量/回复效果复用组件。公共CD跨技能槽与换人保留；下回合不可用的边界属于显式实验策略。 |
| 天气应对 | 汇流接入真正的防御应对判断，雨天延长4/8回合的分支进入实际回合排序与执行。 |
| 普通冻结 | 暴风雪、霜降等普通技能不再因缺阈值处理器假标可用。普通与天气冻结共用阈值、免疫与每段伤害检查；界面显示两种来源层数之和。 |
| 寄生 | 孢子等技能可施加来源绑定的寄生。依据patch3描述保留2%伤害和敌方等量恢复；伤害基数、层数乘法、取整、后备来源恢复、重施后的归属均明确为研究策略。草免疫，实际损血作为回血上限，不复活倒下来源。 |
| 状态生命周期 | 通用层数上限、叠加/覆盖、持续刷新、衰减、到期和离场处理接口；当前自动适配冻结/寄生，未自动执行全部BUFF表。 |
| 技能费用 | 支持按技能ID保留永久/限时修正、使用后触发、回合末触发、对方本轮所选技能绑定。费用在实际行动时重算，最低0；未把未来费用修改当作一次扣能。 |
| 吸血与禁足 | 复用基础伤害执行器，吸血按实际扣血恢复，包括过杀；条件从组件读取。禁足有持续时间、到期解除，主动换人检查沿用统一规则。 |
| 借用/取念/复写 | 每回合冻结候选池后生成，保留真实四槽、生成来源、完整候选及PRNG状态。取念/复写减耗进入实际支付。相同状态重试不重抽；不筛掉未实现技能来伪造抽样分布。生成中的蓄力技能保留至释放。 |
| 能力标记 | 将描述结构化、组件可执行、完整对战可执行和实战校准分别报告。未知操作、未知状态和没有执行器的防御组件不能仅凭compiled进入可用清单。 |

### 配置覆盖

当前579技能中208项通过当前组件准入，371项仍有完整语义阻断。相较上一轮183项准入，新增25项；普通冻结/寄生此前已被误标准入，这次补实执行，不重复计算为新增。三个生成技能在回合开始转成实际技能，依抽中技能分别校验，不能简单计为三个完整技能新增。

11个防御配置：防御、防反、酶浓度调整、蜡质膜、纤维化、水泡盾、刺盾、不动如山、雪替身、报复、虚化。

14个组合配置：冲撞、重击、水炮、抛石、汲取、蝙蝠、龙之利爪、石锁、撕裂、暗突袭、困兽、水刃、天洪、操控。

技能数值与条件保存在 `data/rules/reviewed-*-components-1.json`；运行时不拆句、不删除未解释文字。通用执行器按组件操作、目标、条件和时点分派。防御配置也已离线生成，运行时只核对结构化内容和来源哈希。

## 来源与实验边界

- 魔力：已提取PVP_CONF、BATTLE_CONF、BATTLE_GLOBAL_CONFIG，三表哈希锁定。
- 防御：保留BWIKI完整技能/术语记录，以及SKILL→EFFECT/BUFF→BUFFBASE四表原始引用；例如防御引用20110110→2011011，原参数保留-7000。未把cast_moment和清除/衰减数字直接解释成已确认时序。
- 组合配置：每项绑定当前BWIKI技能记录哈希，并附安装文件对应SKILL_CONF原记录，版本差异保留。
- 寄生：patch3 BUFF20050010原文与SHA；历史基础包不同描述不覆盖当前绑定版本。
- 动态技能：沿用已有候选池与解包引用，确定性均匀抽样、生成时点、递归处理、蓄力保持策略均命名为实验。
- 仍未恢复权威伤害/面板公式与所有事件顺序。公开候选公式、取整及顺序继续标记未校准。

本轮继续只读提取PLAYER_MAGIC_CONF、BAG_ITEM_CONF、BATTLE_ITEM_CONF及相关脚本，保存于 `artifacts/core_magic_20261025/`。

- 愿力强化104002→PlayerMagic100002→Skill7010020。战内次数字段为2；不能拿背包初始次数99代替。PlayerMagic.round=3与SKILL.cd_round=[4,0]分别保留。还包含额外BUFF与驱散，不能只实现首槽替换。
- 进化之力104007→100007→7010070，存在223对形态映射。只更改form_id不能代替HP、面板、技能、血脉、信物条件与状态的完整迁移。
- `core_magic_runtime.inspect_core_magic`提供字段与具体阻断，执行门不消耗资源也不改变槽位。两项均未标为可执行。

仍未完成：通用印记与奉献/传动、全部特性/血脉触发、全部状态互斥与BUFF枚举、巧变/永久替换的自动执行、复杂连击与另外三种蓄力、强制换人/复活、完整核心魔法。已有记录页的巧变与永久槽更新仍保留，但不冒充自动试战实现。

50回合边界和同时魔力耗尽会返回明确待核实裁定，不猜胜者。低能量因中途加费而不够时保留具体阻断及已提交行动，不把事务回滚冒充真实游戏撤销。
