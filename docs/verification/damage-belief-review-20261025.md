## 核验的边界

每个原始候选都必须提供明确的非空分布，包括当前零概率候选。重复结果、非法概率、总质量不为一、缺少候选会拒绝，不能静默合并、补齐或归一化。观测容差只积分显式支持点，不把支持范围中间的空隙填成均匀概率。重复事件按规范化后的证据去重，事件 ID 被不同证据复用时拒绝。

来源只接受调用者声明的 id 与 snapshot_id，输出仍为未验证。不同快照的 PMF 观测不混用；旧均匀区间观测继续标为独立的 likelihood 类型，不能由新 PMF 来源替它证明版本或准确性。schema 3 保存原先验与事件并重放；schema 1/2 可读取旧语义，但不能冒充新 PMF 存档。

内部对数权重保留浮点显示范围以下的非零候选，后续证据可以恢复；真正的零先验或零似然仍不能复活。不可能观测保留最后一致后验并进入 mismatch。隐藏的非零候选若没有已知四槽，也不能让槽位概率被误认为完整已知。

## 复核中修正的问题

前端最初允许 PMF 摘要缺少预测来源，或在显示正概率候选的同时将其列为显示下溢。实现方已加入相互一致性检查；最终源码检查与第 17 项 Node 回归确认这些输入被拒绝。当前未发现剩余阻断问题。

这些验证证明指定概率模型的计算和输入边界，不证明伤害预测器正确、热门阵容先验可靠或完整游戏已校准。新增真实 PVP 校准案例为 0，正式训练资格仍未开放。
