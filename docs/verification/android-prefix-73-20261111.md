# Android 0.10 上行前缀兼容

用户返回的0.8导出包记录设备为HUAWEI TAS-AL00、Android 12/API31，游戏版本1.112.0.116。VPN转发和握手均成功，首条上行业务记录因`ok_unparsed`使分析暂停。该样本属于安卓运行环境，不构成原生鸿蒙适配证据。

## 原因与修复

实录中的上行消息使用`0x0073xxxx`操作码字，低16位与紧邻回显相同。既有实现只将`0x0078xxxx`认定为已确认手机布局。未知布局的完整字段表准入因此拒绝了带新增字段和空正文的合法请求。

共享解析器增加已经由当前实录验证的`0x73`前缀，和`0x78`复用同一路径。原始操作码及外层字保持原值，不推断前缀与品牌或版本的对应关系。未知前缀继续走既有严格准入，封装长度、序号、尾标、保留字、操作码回显、已知字段类型、嵌套边界及非法变长整数检查保留。

原始流量及会话信息只保存在用户提供文件和本机忽略目录。结构报告为`artifacts/app/mobile-huawei-initial-replay.json`、`mobile-huawei-fixed-replay.json`、`mobile-10-huawei-pve.json`及`mobile-10-huawei-pvp.json`。打包身份与签名记录在本机`mobile/build/android-0.10-verification.json`。临时取证和冒烟脚本完成后删除。
