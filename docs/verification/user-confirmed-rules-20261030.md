- 仍为PVP 6v6；原生AMAGO、Metamon网络组件和现有塑形奖励不变。本轮未进行新训练，不能据此声称策略能力提高。

- 每个玩家只能提交自己的替补选择。双方脱离按原速度规则结算；当前RL控制约定为 `own_reserve_precommit_v1`，较慢方不能看到较快方的新入场后再决定替补。完整反应式回合中决策尚未实现，不能宣称完全复刻这一决策时机。
- 己方完整配置可见，敌方未暴露四槽保持未知；只记录实际施放。未使用的敌方替补预选不写公开历史；愿力临时首槽恢复不抹掉已用技能历史。
- 候选闭包检查会递归检查复写／巧变候选。不会删掉尚不支持的随机结果来凑可训练队伍。最高进化阶段默认传说解锁依据为用户确认，资质默认10仍保留为导入假设。
- 每次阵容审计绑定实际源码、规则和审计器版本。研究准入不代表正式校准门禁通过。
