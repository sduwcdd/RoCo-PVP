# BWIKI 数值资料补充：历史实测候选

本轮发现两份此前未收录的 BWIKI 作者资料。它们提供可检验的旧版候选规则，**没有证明当前 S4 六精灵单打一致性**，不应替换现有快照或直接开启正式训练。本轮没有修改引擎。

## 灼烧实测

[作者文章，修订 33421](https://wiki.biligame.com/rocom/index.php?title=以燃薪虫灼烧为例解析洛克王国世界伤害计算机制&oldid=33421) 标注撰文日期 2026-04-02，最后修订 2026-05-08；主体为燃薪虫 PVE 测试。原始 API 响应、维基正文和哈希保存在 `data/reference/bwiki-numeric-20261025/`，目录中的 `manifest.json` 记录来源。

作者提出的候选为：灼烧生命基数取目标最大生命且封顶 1000，每层取 2%；回合末再受属性克制和相关减伤影响；技能“充分燃烧”在回合内触发时按真实伤害处理；半数剩余层数向上取整。文章的 Boss 表中，4000 生命、30 层灼烧对应回合内 600，回合末在 0.8 减伤与 0.5/2 克制下为 240/960，可复现其算术。另有野怪表支持“最大生命”解释，但最大生命是作者根据显示百分比反推的近似值，不能据此唯一确定实际伤害取整。

这些是作者实测与推论，非官方协议；不能扩大到所有“回合中触发”的技能、所有百分比伤害或中毒。表中末回合伤害可能大于剩余生命，不能把报道的伤害数字直接当成实际生命差值。文章虽称无伤害波动，但未提供覆盖所有技能和当前版本的证据。原始完整录像、双方所有状态及当前版本重测仍缺失。结构化表格证据与候选范围见同名 JSON。

## 速度公式候选

[PVP 一速榜，修订 29807](https://wiki.biligame.com/rocom/index.php?title=PVP一速榜&oldid=29807) 明确写于 2026-04-15，给出：

`实际速度 = (1.1 × (速度种族值 + 3 × 个体值) + 10) × 性格修正 + 努力值 + 特性修正`

该榜默认个体值 10、增速性格系数 1.2、努力值 50。文章未给取整顺序、等级泛化、其他性格系数或其他五维公式；不能据此推定阵容码中重复的个体标记具有完整数值。本轮 Web 页面读取成功，API/raw 重试返回 HTTP 567，故同名 JSON 保留读取摘记与明确的存档缺口，未伪造原始响应哈希。

## 排除的线索与检索边界

- 旧站菜单中的“伤害计算器”当前修订 33804 是空正文，历史中唯一上一修订 33544 也只是占位文字，没有可移植公式。已保存 API 历史，不能因存在入口而声称找到计算器。
- 新站 `Module:Pets` 修订 19302 的六维区域展示种族值，相关 `math.floor` 用于条形图宽度；不是实际面板公式。
- 新站游戏描述图鉴可访问，仍为已有的 54 条 Terms；没有新增普通能量上限、魔力初始值或复活判定。
