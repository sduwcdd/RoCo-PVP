# 复合技能与生命回复独立复核

日期：2026-10-25。范围为 BWIKI v2 技能描述编译、隔离效果执行及双方行动片段的调用边界。仅写本报告，未修改实现或测试。

## 已核验

- 当前快照 579 个技能仍全部有记录，完整可解释描述由 138 增至 149；其余 430 明确 unsupported。与保留的 v1 产物逐项比较，原 138 个已编译技能的操作和术语依赖没有改变。
- 新增语法逐个匹配完整子句，并要求所有子句可解释。条件、选择、时序、未知尾句及未解析备注不会被删掉后当作普通技能；攻击类别与来源 kind 不一致时不输出操作。
- 生命回复以精确有理数计算；百分比基数、取整和生命上限处理均须显式给出实验政策。保留未取整量、取整后请求量、实际回复及溢出，未把溢出直接丢弃。
- 静态前置检查先验证整段技能；缺少后续政策或未实现冻结、寄生等依赖时，不会先支付费用或调用伤害解析器。
- 复合伤害后的动态生命检查已加入：只要任一方生命归零，后续状态、回复或返还能量都会阻断，并回滚整段技能。不能仅依赖执行前的存活检查，也不能未经验证跳过力竭触发链。
- 原有双方行动执行器继续在任一片段失败时整体回滚，并阻断已有冻结、未知次序、换人、蓄力、防御与力竭后续。新回复操作没有打开正式训练或完整回合标志。
