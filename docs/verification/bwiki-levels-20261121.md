## 等级处理

旧 PVP 伤害曾固定使用60级系数。
旧大世界伤害拒绝60级以上输入。
当前共用 `damage_at_level`。
60级仍走原先已校准计算分支。
其他等级复用原包等级系数候选。
系数为 `(0.45 * level + 10) / 41`。
这是候选公式，并非新增实战证据。

等级读取 `battle_common_pet_info.level`。
工具不把 `raw_level` 当作实时战斗等级。
工具不会额外叠加特性的39级。
这样可避免对已变化等级重复加算。

恶龙的奢望：低于80级受伤增加40%。
圣龙的心愿：低于80级受伤增加30%。
圣龙的守护：低于80级受伤增加30%。
80级不触发上述受伤增加。
新倍率使用精确比例，避免浮点少1。
超能阿布的累计物攻仍明确阻断。
原因是尚未找到可核对的升级次数。

反推历史现按精灵、形态和等级隔离。
等级变化后，工具清除旧面板和区间。
下发资质和加点选择继续保留。
缺少新等级面板时，不沿用旧等级面板。
非60级PVP尚不外推未知资质公式。
工具只展示已下发的面板与资质。
