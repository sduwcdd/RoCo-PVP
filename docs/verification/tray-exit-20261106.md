# 托盘退出与安装占用修复

用户已从托盘退出，但本机仍有PID 22180的管理员采集进程。其归属记录位于用户数据目录capture-owner.json。主Electron和工作台已退出，残留采集后端占用安装文件。通过已安装capture-control Stop及正常UAC流程停止该进程，助手返回ok/stopped，随后确认归属记录删除、该进程消失。未按进程名称批量终止，也未操作游戏或外部服务。

根因是desktop.js的before-quit只同步关闭HUD和工作台，没有停止独立提权的采集进程，也没有等待子进程退出。修复后退出和安装前清理共用stopOwnedResources：等待未完成的采集控制、停止归属采集、等待HUD退出、等待本APP工作台退出，再允许app.quit。停止失败或UAC取消时保留主窗口与托盘并说明尚未退出，允许重试；停止过程中禁止新建服务的IPC操作。HUD归属不再提前清空。工作台启动失败不会导致退出误报外部进程。

采集控制Promise从健康查询阶段就被记录，避免退出时尚无归属记录、授权后却才创建采集进程的竞态。继续使用后端原有的PID、创建时间、路径与归属类型检查；不停止未归属服务。

3项生命周期定向检查和4项更新检查通过，覆盖待授权启动、取消停止、等待HUD真实退出、停止失败保留归属及重复退出。真实桌面启动/工作台/更新设置验证通过，验证程序退出后未发现APP或后端残留。旧残留采集已实际停止；新版本带真实采集的完整托盘退出仍需实际使用验证，不能把mock测试当成该项实测。
