# 参考伤害与超能阿布修复

日期为2026-11-21。
源码沿用当前RoCo项目。
活动BWIKI快照保持不变。

## 参考伤害

区间改为最低 / 参考 / 最高。
参考值不是区间平均数。
该项个体值按未加点计算。
性格减益不计入参考值。
已知性格加成仍然保留。
未知正性格不擅自视为已知加成。
左侧使用敌方对应防御的假设。
右侧使用敌方对应攻击的假设。
当前状态、特性和天气继续参与计算。

计算复用现有面板候选与伤害函数。
参考查询不修改真实精灵或对战状态。
实际最低与最高范围保持原样。
参考假设可能不满足已有实战约束。
因此不将参考值硬压入实际范围。
其他未知条件仍以参考区间表示。
已确定的伤害仍只显示一个值。

普通、应对、选择与多段攻击均已接入。
技能查询、听桥与替补查询复用同一格式。
愿力分组继续保留未知条件。
多段技能按每段参考值乘固定段数显示。
安卓面板复用同一份HUD页面。

## 超能阿布实录

检索了当前安装版回放数据库。
数据以只读方式读取，包含实时WAL记录。
新证据保存在 `data/reference/live-abu-levels-20261121.json`。
该文件只保留匿名数值和字段来源。

资料中的common.level一直是60。
战斗等级来自inside.field_91。
增量等级来自pet_sync_info.field_40。

首场1178号片段显示84级变身。
圣龙狂斩结算后，等级同步为74。
1179号片段给出完整74级面板。
另一场变身及后续同步均为82级。
两个字段不需要再加特性等级。
目前仅为已实证的阿布家族和冥古龙读取。
其他形态继续沿用原等级来源。

74级物攻基础面板为262。
物攻净百分比槽给出110%。
守护14层贡献70%。
普通物攻增益4层贡献40%。
最终物攻候选为262乘2.1，即550.2。
总百分比存在时，不再重复叠加层数。
相关状态变化后，旧总量会失效。
总量未知时，回退已确认的守护层数。
缺少两种证据时，继续明确阻断。
未用历史24层冒充当前14层。

资料里的60级基础面板也已隔离。
资料等级与战斗等级不同时，不复用旧基础值。
真实下发的资质和三项选择仍保留。
等级变化后，清除旧等级面板与反推。

## 面板候选范围

60级仍走原精度候选路径。
临时战斗等级另用同源五星成长系数。
适配限定五星PVP阿布与超能阿布。
未扩展其他精灵或大世界星级规则。
62、74、82、84级共24项实录面板吻合。
战斗降到60以下时，PVP仍保持五星。
这些未实测等级保留候选标记。
大世界原等级低于60时仍按零星处理。
本轮未更改基础伤害公式。

未扩大未知字段的通用放行范围。
