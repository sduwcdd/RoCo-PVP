# 游戏配置语义核验（2026-10-25）

本次只静态读取已提取配置和重建 Lua；不执行游戏脚本。JSON 附件保存完整分类计数、按类型关联的技能数、原始案例链、精确行号与 SHA-256，供候选转换器校验。

## 可以绑定的字段

- `EFFECT_CONF.effect_order` 是 `Data.Config.Enum.EffectType` 操作码：81 种实际值、1,259 行均可注释到 92 个符号中的一个。
- `BUFFBASE_CONF.buffbase_order` 是 `Data.Config.Enum.BuffType` 操作码：150 种实际值、2,813 行均可注释到 160 个符号中的一个。
- `BUFF_CONF.buff_group_reduce[].reduce_type` 在剩余时间展示函数中使用 `BuffReduceType`。这是展示代码证据，不能据此声称完整过期结算已恢复。
- 字段名中的 `order` 在这些用法中表示效果类别，不能当作事件先后顺序。

上述符号名称来自新提取的可读 `Data/Config/Enum`；字段绑定则来自实际读取和比较。符号注释不等于参数语义或可执行机制。
