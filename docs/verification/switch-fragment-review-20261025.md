## 实现检查

- 入场四槽和空槽完整保留；费用是显式输入，不从技能基础能耗补值。已知能量不足者可跳过；靠前迅捷标识或可负担费用未知时阻断，不能落到后面的技能。
- 有可触发迅捷时，整个换人片段拒绝，因为对应入场技能尚未执行。调用者提供 swift=false 无法绕过图鉴中的迅捷。未知也不会当作无迅捷。
- 当前、目标和对方在场成员的资源、状态与具体形态属性均检查；未知精灵、重复成员 ID、重复技能、错误技能槽和过期蓄力记录拒绝。
- 主动离场禁足、出入场蓄力、正层数冻结/寄生和参与者力竭明确阻断；刚入场的回合不被错误地扩大为禁止主动换人。
- 成功只改变己方 active_slot 与目标 entered_turn，其他成员、资源、状态、字段和印记保留。副本互不共享；失败返回原状态与空事件。
- 印记保留继承来源，不把保留等同于结算印记效果。入场回合可供后续脱离免疫判断；新在场成员 ID 与原技能槽可被后续独立技能片段消费。该组合测试不允许真实一回合额外出招。
